# Nexa AI Local Bridge

Windows-side companion for **Nexa AI Computer Bridge**.

## What v1.0.0 does

- Connects outbound over HTTPS to the Hostinger `api/agent.php` endpoint.
- Authenticates with the pairing token generated by the Hostinger dashboard.
- Sends a real heartbeat every 20 seconds.
- Reports PC name, Windows version, local IPv4, GPU and agent version.
- Reads `bridge_enabled`, `emergency_stop`, `full_computer_mode` and all server permissions.
- Stores the pairing token with Electron `safeStorage`.
- Provides reconnect, disconnect, unpair, auto-connect, Start with Windows, tray operation and safe local logs.
- Does **not** fake remote command execution. The command queue/MCP execution layer is the next component.

## Import into Nexa App Builder Pro

Create a new project with:

- Project name: `Nexa AI Local Bridge`
- Slug: `nexa-ai-local-bridge`
- Foundation: `Cross-platform Desktop · Electron`
- Approval: `Automatic for safe changes`
- Repair attempts: `3`
- Import ZIP: this ZIP file

Then connect the project to the GitHub repository `Nexa-AI-Local-Bridge`, verify it, push source, and run the Windows build.

## Runtime pairing

Enter the Agent Endpoint shown by your Hostinger control center, e.g.:

`https://YOUR-DOMAIN.com/api/agent.php`

Then enter the one-time pairing token generated in the web dashboard and press **Test Connection** / **Connect**.
